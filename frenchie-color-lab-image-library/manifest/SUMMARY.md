## Axes

| Axis | Values | Rule |
| --- | --- | --- |
| base | standard, fluffy, hairless | Hairless (N/Dup) overrides Fluffy (l/l). |
| coat | solid, fawn, sable, and-tan, husky, cream-white, cream, platinum, pink | Pink > e/e (Cream/Platinum) > K and Agouti; In/In turns fawn and sable grounds Cream/White. |
| pigment | black, chocolate, cocoa, new-shade-rojo, blue, isabella, lilac, new-shade-isabella, none | From expressed Brown, Cocoa, and Dilute; none on Cream, Platinum, and Pink coats. |
| mask | 0, 1 | Eᴹ on fawn, sable, and non-brindle Cream/White faces only. |
| brindle | 0, 1 | kᵇʳ without Kᴮ over a fawn, sable, Cream/White, or And Tan pattern (one representative map). |
| merle | 0, 1 | M/m on eumelanin-bearing coats or brindle stripes (one representative map). M/M uses a safety panel. |
| pied | 0, 1 | S/S where the white map is distinguishable: not on Cream, Platinum, Cream/White, or Pink. |
| eyes | dark-brown, light-blue, blue | Derived, not an independent axis: Pink → light blue; visible Merle → blue; else dark brown. |
| bigRope | 0, 1 | Visual preference only; never genetic. |
